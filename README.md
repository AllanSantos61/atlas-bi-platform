# Atlas BI — Business Intelligence & Management

Plataforma demonstrativa e independente de **Business Intelligence e gestão empresarial**, criada para portfólio profissional.

## Funcionalidades

- Dashboard executivo com receita potencial, receita recebida, projetos e metas
- Gestão demonstrativa de projetos, tarefas e clientes
- Filtros por ano e responsável
- Indicadores financeiros e metas editáveis
- Persistência local via localStorage
- Interface responsiva

## Executar

Abra o arquivo `index.html` no navegador. Nenhuma instalação é necessária.

Para publicar no GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

Após a ativação, o endereço esperado será:
https://allansantos61.github.io/atlas-bi-platform/

## Segurança e escopo

**Todos os dados são fictícios.** Este projeto não utiliza código-fonte, credenciais, informações pessoais ou dados financeiros de clientes. É uma demonstração independente; não possui backend, autenticação ou banco de dados em nuvem. Os registros criados ficam somente no navegador do visitante.
